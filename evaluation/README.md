# Evaluación

Esta carpeta está reservada para la evolución del proyecto hacia una evaluación reproducible.

En v1.0 todavía no existe un benchmark formal.

La planificación inicial contempla:

1. construir casos controlados;
2. definir una salida esperada;
3. ejecutar el pipeline;
4. comparar resultado y referencia;
5. clasificar errores;
6. calcular métricas.

No incorporar datos clínicos identificables al repositorio.
